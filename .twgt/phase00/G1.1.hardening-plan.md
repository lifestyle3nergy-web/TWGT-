## Executed (R2 authorized 2026-10-29)

`twgt-schema-gate` and `twgt-git-hitl` now have:

- Require pull request before merging
- Require at least 1 approval
- Dismiss stale reviews on new commits
- Block force pushes
- Block deletions
- No required status checks yet (added in P02)

## Remaining

- twgt-bridge: harden at P04
- twgt-device-node: harden at P03
- twgt-knowledge: no feasible action on current plan
- libs: harden at P03
- backstage: harden before P05

## Justification (historical)

P01 publishes the package that P02's gate will validate against. If
twgt-schema-gate is unprotected, a merge to main can weaken the gate
that validates P01's outputs. P01's publication merges via
twgt-git-hitl. If twgt-git-hitl is unprotected, its merge authority
can be bypassed without review. Both are now protected.
