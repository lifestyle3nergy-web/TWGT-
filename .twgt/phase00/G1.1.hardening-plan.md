## Justification for hardening-before-P01 on the two critical repos

P01 publishes the package that P02's gate will validate against. If
twgt-schema-gate is unprotected, a merge to main can weaken the gate that
validates P01's outputs — bypassing the gate that P01 depends on. This is
a circular-trust vulnerability.

P01's publication merges via twgt-git-hitl. If twgt-git-hitl is
unprotected, its merge authority can be bypassed without review.

## Proposed protection rules (minimal, matching TWGT-'s model)

For twgt-schema-gate and twgt-git-hitl:

- Require pull request before merging
- Require at least 1 approval
- Dismiss stale reviews
- Require status checks (list to be determined; start with none and add
  checks as P02 defines them)
- Block force pushes
- Block deletions
