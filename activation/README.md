# Activation Boundary

Activation artifacts are isolated from the existing runtime baseline.

Allowed categories:

- `config/` — declarative activation configuration
- `schemas/` — machine-readable contracts
- `prompts/` — activation prompts and instructions
- `protocols/` — activation protocols
- `scripts/` — bounded activation support scripts
- `state/` — non-secret activation state definitions
- `evidence/` — validation and provenance evidence

Do not place secrets, production data, dependencies, build output, or general application code here.
