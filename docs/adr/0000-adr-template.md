# ADR-0000: Architecture Decision Record Template

- **Status:** Template
- **Date:** YYYY-MM-DD
- **Decision owners:** TWGT maintainers

## Context

Describe the problem, constraints, existing boundary, and evidence that require a decision.

## Decision

State the decision precisely, including the repository boundary affected.

## Consequences

Describe positive, negative, operational, security, maintenance, and migration consequences.

## Alternatives considered

List credible alternatives and why they were not selected.

## Validation

Define the checks that prove the decision remains true.

## Reversal / migration

Describe how the decision can be reversed or migrated without bypassing governance.
